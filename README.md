# Pulso Económico

Noticias reales de **economía del Perú**, **economía internacional** e **inteligencia artificial**, enviadas por Telegram a las 8:00, 14:00 y 19:00 (hora de Lima), con una página web instalable como app.

- Programa: `noticias.py` (Python, sin dependencias)
- Personalización: `config.json`
- Horarios: `.github/workflows/noticias.yml`
- Página web: carpeta `docs/` (GitHub Pages)
- Guía paso a paso: `GUIA.md`
